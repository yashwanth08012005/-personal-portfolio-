# Personal Portfolio

This is my personal portfolio website, built using **React + Vite**, and designed to showcase my résumé, skills, and projects.

## 🚀 Features
- Responsive design for desktop and mobile
- Sections for About, Skills, Projects, and Contact
- Built with React components and modern styling
- Easy to update with new achievements

## 🛠️ Tech Stack
- React + Vite
- JavaScript (ES6+)
- CSS / Tailwind (if used)
- GitHub Pages (for deployment)

## 📂 Project Structure
- `src/components` → Reusable UI components
- `src/assets` → Images and icons
- `public` → Static files
